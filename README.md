# Project Luna

## Name
### Meaning

Luna is the Latin word for "moon."

It’s also the Roman goddess of the moon, the counterpart to the Greek goddess
Selene.

The name represents light in darkness, cycles, mystery, reflection, and
creation.

### Symbolism

In mythology, literature, and modern branding, Luna often symbolizes:
- Creation and rebirth (the moon’s changing phases).
- Illumination (bringing light to the night).
- Balance (reflecting sunlight rather than producing it).
- Emotion, intuition, and imagination.
